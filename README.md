# RAP Travel Management – ABAP

## Overview
This project demonstrates the use of the **ABAP RESTful Application Programming Model (RAP)**
generated using the RAP Generator Wizard in ABAP Development Tools (ADT).

## Key Features
- Managed RAP scenario
- CDS-based data model
- Behavior definitions for transactional processing
- OData V4 service exposure
- Ready for Fiori Elements consumption

## Technical Artifacts
- Database Table
- CDS View (Interface & Projection)
- Behavior Definition & Implementation
- Service Definition
- Service Binding

## Tools & Technologies
- SAP ABAP (RAP)
- ABAP in Eclipse (ADT)
- abapGit
- GitHub

## Notes
ABAP source code resides on the SAP system.  
This repository contains the version-controlled RAP artifacts exported using **abapGit**.
